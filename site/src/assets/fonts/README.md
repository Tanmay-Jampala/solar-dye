# Fonts

The display face is **General Sans** (Regular and Medium) by the Indian Type Foundry, distributed free
through [Fontshare](https://www.fontshare.com/fonts/general-sans) under the ITF Free Font License
(`FFL.txt`). The licence allows self-hosting the font on your own website, but not redistributing the
font files through a repository, so they are not committed here.

To build the site, download General Sans from Fontshare and copy these two files into this folder:

- `GeneralSans-Regular.woff2`
- `GeneralSans-Medium.woff2`

IBM Plex Mono (SIL Open Font License) is installed from npm (`@fontsource/ibm-plex-mono`).
